# R.E.E M&E – Style reference (chosen by Triet, 2026-10-15)

Reference images: `design/style-refs/ref-*.{webp,jpg}` (luxury real-estate poster series).
Use them as the visual reference for every new section or redesign.

## Palette & light
- Deep night-navy sky (#071a3a → #0b2a5e) fading to a teal/blue horizon, warm golden-hour glow at the bottom (sunset peach/amber, never pure orange).
- Vertical "light column": a brighter royal-blue band (#0f3a9e → transparent) behind the hero subject, with 1px hairline edges.
- Accents: thin blue hairline rules (often 3 segments: long–short–long), soft white glass, occasional champagne/gold for highlight words.
- Brand red stays only as small accent (eyebrow, active bar), never large fills.

## Typography
- Large, elegant, light-to-regular display type, generous size, tight leading.
- Script accent word (Great Vibes, already self-hosted at `assets/fonts/gv-*.woff2`) paired with a hairline.
- Wide-tracked uppercase small eyebrows.

## Components
- Frosted glass panels: thin 1px light-blue border, rounded 8–12px, faint navy fill + blur.
- Pill bars: white/pearl glass pills, sometimes with round icon badges, dividers between items.
- Outline triangle/chevron line ornaments in corners, very faint.
- Photos: architecture at dusk, lit interiors; images fade into the navy via gradients (no hard edges between sections).

## Rules agreed with Triet
- Style only — do not add or remove content unless asked; never swap a provided image for another.
- When given a reference image as a background: remove its text, logos, icons, buttons (and buildings if asked).
- After any edit, the preview opens on the edited page/section (`__REE_FOCUS` in the artifact index.html).
